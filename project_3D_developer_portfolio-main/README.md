# Tobby — 3D Developer Portfolio

A customized React + Vite portfolio built from the supplied 3D template.

## Highlights

- 3D hero scene
- Scroll-driven horizontal project showcase
- Real project data and links from `Tobby1234566` on GitHub
- Live previews for LUMÉRA and AuditPulse
- Responsive stacked project cards on mobile
- Accessible navigation and reduced-motion support

## Run locally

```bash
npm install --legacy-peer-deps
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Deploy the `dist` folder to Vercel, Netlify, or any static host.
